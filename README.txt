KazShipService website package
==============================

What is inside
- index.html: ready-to-use website
- assets/logo.png: company logo

How to run locally
- Open index.html in any browser.

How to upload to hosting
- Upload index.html and the assets folder to your hosting root.
- If your hosting uses a public_html folder, place the files there.
